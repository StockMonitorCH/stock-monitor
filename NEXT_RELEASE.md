## Neue Features

- **Doppelklick zum Zoomen:** In der Übersicht öffnet ein Doppelklick auf einen Chart den Zoom-Modus; ein weiterer Doppelklick schließt ihn wieder (Vorschlag eines Users aus Australien)

---

## Verbesserungen

- **Steuerdaten 2026:** Alle Steuersätze für CH, DE, AT, UK und USA auf Steuerjahr 2026 aktualisiert
  - UK: Dividendensteuer erhöht auf 10,75 % / 35,75 % / 39,35 % (Basic/Higher/Additional, ab 6. April 2026)
  - UK: CGT auf 18 % (Basic) / 24 % (Higher), unverändert seit Autumn Budget 2024
  - CH, DE, AT, USA: Sätze unverändert, Jahresfelder auf 2026 aktualisiert
